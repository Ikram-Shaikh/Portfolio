# React + Vite (template notes)

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Two official plugins are commonly used:

- `@vitejs/plugin-react` — uses Babel for Fast Refresh.
- `@vitejs/plugin-react-swc` — uses SWC for Fast Refresh.

## React Compiler

The React Compiler is not enabled in this template; see the React docs for installation instructions.

## Expanding the ESLint configuration

For production apps consider TypeScript and `typescript-eslint`. See the Vite template for guidance.
